# Measuring Starlink Aviation Around the World

This repository contains the dataset and reproducibility artifacts associated with the paper ***Measuring Starlink Aviation Around the World***, accepted at the 2026 ACM Internet Measurement Conference (IMC '26).

The repository will be updated in **September 2026** after the collected dataset has undergone appropriate anonymization and processing.

The Starlink MPLS labels to PoP mapping is available at https://github.com/clarkzjw/starlink-geoip-data/tree/master/mpls.
